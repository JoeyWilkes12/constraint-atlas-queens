# Overview

Constraint Atlas — Queens is an existing, browser-native constraint-modeling
workbench. Its production artifact is generated by `npm run build:pages` and
contains static HTML, CSS, JavaScript, and an Open Graph image.

# User Preferences

- GitHub `JoeyWilkes12/constraint-atlas-queens`, branch `main`, is the
  authoritative source and the only approved input for final Replit
  deployments.
- Do not publish uncommitted or Replit-only application changes.
- Manage Preview, the static build, deployment configuration, logs, social
  metadata, republishing, and production verification.
- Do not rewrite, regenerate, refactor, or redesign the workbench unless the
  user explicitly authorizes that work.
- Do not add a server, database, storage, authentication, Autoscale, or
  Reserved VM. Use Static Deployment.

# System Architecture

- Production build: `npm run build:pages`.
- Public directory: `dist/pages`.
- Runtime: browser-only HTML, CSS, and JavaScript.
- State: current browser session only.
- Social image: `dist/pages/og.png`, with its absolute URL injected through
  `PAGES_URL` during the build.

# External Dependencies

- Replit Static Deployment with a public `replit.app` URL.
- GitHub source control and repository visibility are already integrated with
  Replit.
- No package installation, secrets, connectors, database, or object storage
  are required.
